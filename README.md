# PARI MIKI Smile注文書 PWA

`index.html` をHTTPSで公開すると、スマートフォンのブラウザからホーム画面に追加できます。

## 使い方

1. GitHub PagesなどHTTPSで公開します。
2. スマートフォンで公開URLを開きます。
3. iPhoneは共有ボタンから「ホーム画面に追加」、Androidはブラウザメニューから「アプリをインストール」または「ホーム画面に追加」を選びます。

PDF保存には初回のみインターネット接続が必要です（pdf-libをCDNから読み込みます）。画面と入力データはサービスワーカーでキャッシュされ、次回からオフラインでも利用できます。
